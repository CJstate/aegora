# Security Policy

The Aegora project takes security vulnerabilities seriously. We appreciate your efforts to responsibly disclose findings.

---

## Supported Versions

Currently, security fixes are developed and released exclusively against the `main` branch.

| Version | Supported |
|---|---|
| `main` branch | Yes |
| Pre-release / dev builds | Best effort |
| Prior release tags | No |

---

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability in Aegora:

1. Send a private report to the maintainers at:
   **shubhamkashyap0608@gmail.com**
2. Include the following details to help us triage and resolve the issue quickly:
   - A description of the vulnerability and its potential impact.
   - Affected Aegora version, commit SHA, or build environment.
   - Step-by-step instructions or a minimal proof of concept to reproduce the issue.
   - Any suggested mitigations or patches, if available.
3. You will receive an acknowledgment of your report within 48 hours.
4. We will coordinate remediation, prepare a fix, and agree on a responsible disclosure timeline before publicly releasing details.
